梓懿围棋 1.8

启动
适用于 Windows 10 / 11 64 位、.NET Framework 4.8。
已有v1.4.0完整GPU包，或已升级至v1.5.0/v1.6.0/v1.7.0：关闭程序，将v1.8.0升级包内文件解压到原“梓懿围棋.exe”所在目录，覆盖同名文件，再运行更新后的程序。保留相邻的cuda和gpu文件夹，无需重下引擎或模型。
首次使用GPU：先下载并解压v1.4.0基础包，再将v1.8.0升级包内文件解压到同一程序目录并覆盖，最后双击“梓懿围棋.exe”。
本版升级包更新主程序、说明与许可；CUDA/OpenCL引擎、运行库和两个GPU模型沿用v1.4.0基础包。
NVIDIA 电脑优先使用 CUDA；配套运行库由基础包提供，无需安装完整 CUDA Toolkit，仍需兼容显卡和驱动。
其他显卡可使用 OpenCL；首次加载新模型或棋盘尺寸时可能调优数分钟，界面显示启动状态并支持取消。
CPU 单文件已内置 KataGo 1.14.1 与 g170 b10。引擎和模型准备好后，下棋可离线进行。

界面与导航
左侧提供“对局、复盘、截图识别、设置”。对局与复盘使用同一盘棋，页面切换保留当前局面、手数和研究范围。
中央棋盘优先使用窗口空间；下方集中逐手导航与棋谱操作，右侧按对局、引擎、AI操作、形势与推荐分组。
“形势与推荐”使用真实引擎数据。全盘历史图仅显示实际分析过的局面，未分析手数留空；局部结果另行标识，不混入全盘曲线，切换模型或后端后清除旧分析数据。
候选列表显示推荐点、胜率和目差；下在A后的预测走法表示双方可能的后续落子。
截图识别按“上传图片 → 自动识别 → 手动校正 → 导入棋盘”操作，支持图片文件拖入、选择、粘贴和屏幕框选。

引擎与模型
从左侧“设置”、引擎卡片的“设置…”或“帮助 → 引擎 / 模型设置”打开。
1. CPU：程序与模型留空时使用内置资源，也可选择本地程序或模型。
2. CUDA GPU：使用 NVIDIA 显卡和随包的 CUDA 12.1 / cuDNN 9.8 运行库，KataGo 1.18.1。
3. OpenCL GPU：使用显卡驱动提供的 OpenCL，KataGo 1.18.1。
4. 自定义：浏览选择本地 KataGo .exe 与 .bin.gz / .bin。程序需支持 analysis JSON 协议，版本与模型需兼容。
5. CUDA/OpenCL 共用模型下拉列表，默认最强 tf3，同时保留原 b18。日期与完整模型名显示在列表中。
   最强：kata1-tf3-b11c768-s11003M-d5973M-7gres，官方上传于2026-09-25，约7044万参数；本版固定采用截至2026-10-20官方公开榜标记“评分可信的最强”的模型。
   旧 GPU：kata1-b18c384nbt-s9996604416-d4316597426，官方上传于2024-05-26，约2633万参数。
   内置 CPU：g170e-b10c128-s1141046784-d204142634，2020年轻量模型，约299万参数；2020-11-28为官方目录收录日期，原始训练完成日未记录。
6. 确认时检查文件，取消则保留当前配置。切换取消当前分析，棋局保持不变。
7. 首次运行检测到 NVIDIA 且 CUDA 套件存在时默认 CUDA，否则选择可用的 OpenCL 或 CPU。
   旧版内置 GPU 配置升级时可迁移 CUDA并保留模型；版本3已明确选择的后端、CPU和自定义配置会保留。
8. GPU 模型位于 gpu\models；CUDA 引擎位于 cuda，OpenCL 引擎位于 gpu。移动便携包时保留整个目录结构。
启动失败时显示具体原因；可检查缺失文件、驱动和模型，或在设置中选择其他后端。
Windows 智能应用控制可能阻止未受信任的引擎；应用会提示错误，不会修改系统安全设置。

下棋与坐标
默认19路、人执黑、AI自动应手。点击空交叉点落子；分先时执白则AI先行，让子棋按实际先行方应手；选择双方可替黑白摆谱。
列从左向右连续包含 I，19路为 A–S；行从上向下为1–19，左上角A1，右下角S19。
支持9路和13路，分别为A–I / 1–9与A–M / 1–13。引擎通信和SGF保持各自标准格式。
“AI落子”走当前一手；“推荐着点”显示A–E候选及A的变化，最多10步，较短变化按引擎实际返回显示；“形势 / 领地”显示胜率、目差和归属估计。
“AI自弈”让AI替黑白行棋，再次点击停止。悔棋及导航可回看；回看后落子会覆盖后续原变化。
双方连续停一手后结束。形势是AI估计，争议死活可悔棋后继续确认。

截图与照片摆棋
点击左侧“截图识别”、“截图 / 照片摆棋”入口或按Ctrl+I，拖入或选择图片、粘贴剪贴板图片或在屏幕上框选。支持软件棋盘、视频截图及实体棋盘照片。
图像识别由本机CPU完成，可离线使用；研究着法继续使用现有KataGo引擎和模型。
1. 确认全盘为19、13或9路；局部图片还需展开“局部与校准”，设置当前可见的列数、行数。
2. 上传后会自动定位并识别，请先核对格线。拖动原图四角，使其对准可见网格四角的交叉点；实体斜拍按透视网格校正。角点不是木框边缘。图片方向不合适时可旋转。
3. 调整格线后点击“重新识别”。对照原图与识别棋盘，用黑子、白子、擦除工具修改，支持撤销。可连续摆同一种颜色，修正时不按正常轮流落子或自动提子处理。橙圈位置请重点检查，灰色区域可手动补子。
4. 局部图选择所在角边或起始列行，按真实位置放回完整棋盘。截图裁切处不是实际盘边；未拍到的盘外信息未知，在研究局面中先留空。
5. 选择下一手黑或白，确认后导入新的初始局面，随后可研究、继续落子并保存SGF。取消保留原棋局。
截图不能恢复落子顺序、先前提子数量和劫历史，导入棋子属于预摆棋子，不显示原始手数；之后实际落子再开始编号。
源图坐标字母及行号方向可能与本程序不同，以网格位置、方向和所选局部锚点为准。
拍照时尽量让交叉点清晰、棋子无遮挡。模糊、强反光、遮挡和大角度照片需校准并手动修正。
局部题图可结合框选局部研究。全盘胜率和目差仅针对导入后搭建的局面；征子和劫争可能需要补充盘外棋子或扩大范围。

局部研究
1. 点击“框选局部”，按住左键在棋盘上拖出范围。框选不会落子；Esc取消本次框选并保留原研究框。
2. 框内研究保留整盘棋子、轮次、规则、贴目与劫历史。框外棋子保持原位并参与局面评估，棋盘不会缩成一个小棋盘。
3. 黑白双方的搜索着法，以及人和AI的实际棋子落点，均限定在研究框内。可点击“AI落子”“推荐着点”或“形势 / 领地”。
4. 当前方在框内没有合法落点时，程序提示扩大范围或退出局部；不会自动脱先或停一手。征子、劫争、向外逃出的变化可通过重新框选扩大范围研究。
5. 先取得局部推荐，再点“全局对比”，可对照局部A与全局A的坐标。全局对比仅做一次全盘分析，不自动落子，也不清除研究框；下一次AI落子或局部分析仍使用原范围。
6. “退出局部”恢复全盘对弈。新对局或导入SGF会清除研究框，逐手复盘导航保留范围。
局部结果是神经网络与有限搜索在限定应手条件下的建议，不保证数学意义的最优解；全局对比用于判断实战是否应在别处落子。

显示棋子手数
勾选“显示手数”，在当前存活棋子上显示其原始第N手。
停一手计入总手数，但没有棋子编号；开局让子和SGF初始摆子不编号。
被提棋子的编号随之消失，同一点重新落子显示新的手数。
悔棋、复盘导航和建立新分支时，编号随当前局面及有效历史更新。

规则、贴目与声音
左侧“设置”中的规则与声音入口，或“规则 / 设置”，可选择中国 / 日本规则、贴目和让子，应用于下一局。
贴目支持−150至150的整数或半目，始终表示白方所得；让子方向不会覆盖你设置的贴目。
让子方向可选“白让黑（黑棋先摆）”或“黑让白（白棋先摆）”，数量0–9子。
0为分先，黑方先行；1子放天元，2–9子按标准星位摆放。获得让子的一方先摆，对方先行。
点确定只保存下一局设置，再点“新对局”才应用；取消不改变设置和当前棋局。
例如人执黑、AI执白，选“白让黑”9子，再开新局，黑方预摆9子后由AI执白先下。
SGF保存并恢复黑/白初始摆子及先行方，AI按同样的真实局面分析。
落子音量可调0–100%，0%静音；可试听，点确定才生效并保存，取消保留原设置，默认65%。
声音只在真实棋子落盘时播放；停着、载入、回看和悔棋保持安静。

计算量与棋力
预设为256、1024、2048、4096、8192、16384次搜索访问（visits）。GPU启动默认2048，CPU默认256。
同一会话切换后端或模型沿用当前预算。次数不是推演手数，也不对应人类段位。
棋力取决于模型与搜索预算；同一模型和访问量下，CUDA主要提高计算速度。
RTX 4060 Laptop 8GB、同一个最强模型的36次对比中位数：
搜索次数       OpenCL          CUDA
1024           6.90秒          2.18秒
2048          13.16秒          4.28秒
4096          25.03秒          7.70秒
三个19路局面各测两轮；启动和预热另计。此表沿用v1.4.0正式测量。后台游戏、功耗、温度和局面会影响等待时间。
“自定义”可从计算深度菜单或“规则 / 设置 → 设置计算深度”打开。
自定义次数为正整数，单次范围1至1125899906842624（2^50），越界会提示，输入不会被截断。
持续思考使用原生最大预算，由你手动结束；计数仍有限，分析不设置固定时长。
“结束思考并落子”采用当前最佳点；“结束分析”保留推荐或领地结果。
新局、悔棋、棋谱导航、切换引擎和关闭程序会取消相应计算，隔离迟到进度和结果。

联机对弈
当前为本地对弈与复盘，“双方”是在同一台电脑操作黑白。
公网联机需部署房间服务器，提供建房/加入、落子校验、棋局同步及断线重连；设计见源码 docs/ONLINE-PLAY.md。

棋谱与快捷键
支持SGF主变化、初始摆子、先行方及中国 / 日本规则；识别野狐KM[375]等贴目编码并显示转换提示。
← / →：上一手 / 下一手；Home / End：首手 / 末手。
Ctrl+N：新局；Ctrl+O：打开SGF；Ctrl+S：保存SGF。请保存需要保留的对局。
Esc：取消正在进行的框选，保留原研究区域。

本地文件与许可
引擎缓存、配置、日志位于 %LOCALAPPDATA%\GoDesk。
引擎选择保存在 engine-settings.json，音量在 audio-settings.json。关闭窗口同时结束所属 KataGo。
CUDA依赖仅在应用目录内使用，子进程PATH不改变系统PATH，不安装SDK或驱动。
应用源码MIT，CPU g170为CC0，GPU kata1模型为KataGo Neural Network License。
NVIDIA运行库适用随包的专有许可；应用MIT许可不替代NVIDIA条款。
完整许可见“帮助 → 第三方许可”、第三方许可.txt、gpu\licenses、cuda\licenses。

源码构建
在项目根目录依次运行 .\build.ps1、.\prepare-gpu.ps1、.\prepare-cuda.ps1。
准备脚本固定官方下载版本并校验长度/SHA256，-SourceCache可复用缓存。
输出为 release\梓懿围棋-v1.8.0，GPU文件位于相邻的gpu、cuda目录。无需额外NuGet包。
.\build.ps1 -Checks执行图像识别、透视、规则、棋谱、坐标、局部研究、棋子手数、配置、声音及真实CPU检查。
桌面检查：--ui-test 报告路径；OpenCL检查：--gpu-test 报告路径；CUDA检查：--cuda-test 报告路径。
GPU检查末尾可再传模型ID，选择旧b18。
