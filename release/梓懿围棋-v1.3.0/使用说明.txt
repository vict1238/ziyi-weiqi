梓懿围棋 1.3

启动
适用于 Windows 10 / 11 64 位、.NET Framework 4.8。
GPU 完整便携包解压后，双击“梓懿围棋.exe”，保持 gpu 文件夹与主程序相邻。
GPU 采用 OpenCL，需要显卡厂商驱动的计算支持，无需安装 CUDA。首次加载新模型或棋盘尺寸时，调优可能需要几分钟；界面会显示启动状态，可以取消。
CPU 单文件已内置 KataGo 1.14.1 与 g170 b10 轻量模型。引擎和模型准备好后，下棋可离线进行。

引擎与模型
从右侧“设置…”或“帮助 → 引擎 / 模型设置”打开。
1. CPU：程序与模型留空时使用内置资源，也可选择本地程序或模型。
2. GPU：完整便携包使用 KataGo 1.18.1 OpenCL。模型下拉列表默认选择最强 tf3，同时保留原 b18，直接选择即可。
   最强：kata1-tf3-b11c768-s11003M-d5973M-7gres，官方上传于 2026-09-25，约 7044 万参数；截至 2026-10-20 官方公开榜标记“评分可信的最强”。
   旧版 GPU：kata1-b18c384nbt-s9996604416-d4316597426，官方上传于 2024-05-26，约 2633 万参数。
   内置 CPU：g170e-b10c128-s1141046784-d204142634，2020 年的轻量模型，约 299 万参数；2020-11-28 为官方目录收录日期，原始训练完成日未记录。
3. 自定义：浏览选择本地 KataGo .exe 与 .bin.gz / .bin 模型。程序需支持 analysis JSON 协议，版本需与模型兼容。
4. 确认时检查文件，取消则保留当前配置。切换会取消当前分析，棋局保持不变。
5. 完整 GPU 包首次运行默认最强模型；升级时旧版默认内置配置会迁移到最强，新版明确选择和自定义文件配置会保留。CPU 单文件默认内置 CPU。当前后端、模型与日期显示在侧栏、帮助和关于信息中。
6. 自带 GPU 模型位于 gpu\models，以原始文件名保存；移动便携包时保留整个 gpu 目录。GPU 日期为公开上传日期，旧 CPU 模型标注目录收录日期。
GPU 或自定义启动失败时会显示原因，可修正路径、驱动或模型，也可在设置中主动选择 CPU。

下棋与坐标
默认 19 路、人执黑、AI 自动应手。点击空交叉点落子；选择执白后 AI 先行，选择双方可轮流替黑白摆谱。
列从左向右连续包含 I，19 路为 A–S；行从上向下为 1–19，左上角 A1，右下角 S19。界面落子、推荐、进度与复盘采用同一坐标。
支持 9 路和 13 路，对应 A–I / 1–9 与 A–M / 1–13。引擎通信和 SGF 文件保持各自标准格式。
“AI 落子”让当前一方走一手；“推荐着点”显示 A–E 候选；“形势 / 领地”显示胜率、目差和归属估计。
“AI 自弈”让 KataGo 同时替黑白行棋，再次点击可停止。
“悔棋”撤回落子；首手、上一手、下一手、末手可回看。回看后落子会覆盖当前位置之后的原有变化。
双方连续停一手后结束对弈。形势为 AI 估计；争议死活可悔棋回到结束前继续确认。

规则、贴目与声音
“规则 / 设置”可选择中国 / 日本规则、贴目和让子，应用于下一局。贴目支持 −150 至 150 的整数或半目；让子可配合 0.5 贴目。
落子音量可调 0–100%，0% 为静音。“试听落子声音”按当前草稿音量试听；点确定后才修改实际音量并保存，取消保留原设置。默认音量为 65%。
声音在真实棋子落盘时播放；停着、载入、回看和悔棋不播放落子声。

计算量与棋力
预设为 256、1024、2048、4096、8192、16384 次搜索访问（visits）。启动时 GPU 默认 2048 次，CPU 默认 256 次；同一会话切换后端或模型沿用当前预算。次数不是向后推演的手数，也不代表人类段位。
棋力取决于神经网络模型和搜索预算。完整 GPU 包默认 2026-09-25 的最强 tf3，同时保留旧 b18；内置 CPU 保留 g170 b10。GPU 增加每秒可计算的访问数，相同模型与访问次数下硬件加速本身不会升级模型能力。
模型更强、预算更大通常需要更长等待，按实际速度选择；运行中可结束思考采用当前最佳点。“自定义”可从计算深度下拉菜单或“规则 / 设置 → 设置计算深度”打开。
最强模型在 RTX 4060 Laptop GPU 8 GB、OpenCL 上的两个 19 路局面实测：1024 次约 5–6 秒，2048 次约 10–12 秒，4096 次约 22 秒。首次调优约 4 分钟，缓存后加载约 3.2 秒。耗时随机器与局面变化。
自定义搜索次数需为正整数，单次范围为 1 至 1125899906842624（2^50），越界会明确提示，输入不会被截断。
持续思考使用原生最大搜索预算，由你手动结束；计数仍然有限，分析不设置固定时长。
搜索过程实时显示访问次数、胜率和当前最佳点。“结束思考并落子”采用当前最佳着法；“结束分析”保留当前推荐或领地结果。
新局、悔棋、切换棋谱或引擎、关闭程序会取消对应分析，旧结果不会落入新局面。

棋谱与快捷键
支持打开和保存 SGF 主变化、初始摆子、先行方以及中国 / 日本规则。
识别野狐棋谱的特殊贴目编码，例如 KM[375] 转为 7.5 目；实际转换会在状态栏显示提示。
← / →：上一手 / 下一手；Home / End：首手 / 末手。
Ctrl+N：新对局；Ctrl+O：打开 SGF；Ctrl+S：保存 SGF。
请保存需要保留的对局。

本地文件
内置引擎缓存、运行配置与日志位于 %LOCALAPPDATA%\GoDesk。
引擎选择保存在 engine-settings.json，音量保存在 audio-settings.json，错误日志在 logs 文件夹。
关闭窗口会同时结束所属 KataGo 进程。
CPU、GPU 引擎、模型与依赖保留各自许可。GPU kata1 的 tf3 和 b18 使用 KataGo Neural Network License，CPU g170 使用 CC0。许可见“帮助 → 第三方许可”、程序目录的第三方说明，以及 gpu\licenses。

源码构建
在项目根目录运行 .\build.ps1。
如需 GPU 套件，再运行 .\prepare-gpu.ps1；固定版本下载会校验文件长度与 SHA-256，可用 -SourceCache 指定已有缓存。
主程序位于 release\梓懿围棋-v1.3.0，GPU 文件位于相邻 gpu 目录。无需额外 NuGet 包。
.\build.ps1 -Checks 执行规则、棋谱、坐标、配置与真实 CPU 引擎检查；桌面交互检查入口为 --ui-test 加报告路径。
