# 好友房与整盘复盘

两边都使用 2.0。在「联机」创建房间，选择棋盘、执色、规则、贴目和让子，再把邀请私发给好友。对方在加入页粘贴邀请。

- 同一网络内用「局域网」。两台设备需能互通，访客 Wi-Fi 可能会隔离设备。
- 异地用 Tailscale。两边登录后，好友须能访问房主设备。 [Tailscale 连接文档](https://tailscale.com/docs/how-to/connect-to-devices)

房主程序承载房间，只监听选中的地址。邀请通过 TLS 验证房主身份。连不上时检查房主窗口、地址和 Windows 防火墙。掉线后请双方保留窗口，加入者会尝试恢复原席位和手顺。离开前可以保存 SGF。

## 切磋和研讨

切磋房按黑白轮流落子，锁定 AI 和摆棋。悔棋经对手同意后执行。双方停着后确认结果，也可认输。下完可把棋局复制到研讨房。

研讨房中，两边都能摆黑白子、擦除、选下一手，并从棋谱某一手试下。清盘或换棋谱需要双方同意。完成摆棋后可运行本机 KataGo。共享结果附带模型、搜索次数和变化，局面一变就清除旧标记。

## 看懂整盘报告

导入 SGF 主线后选预算并开始分析。报告有测评、吻合度、胜率与目差、问题手和发挥分布。点手数可回到落子前。深度复算另显示该手结果。

| 指标 | 算法 |
| --- | --- |
| 一选率 | 实战落点精确命中 AI 首选的比例。 |
| 目损 | 从落子方视角，比较同一局面的首选与实战手。实战着点搜索不足时会补算。 |
| 好手率、恶手率 | 默认一选或目损不超过 1.5 目计为好手，目损达到 6 目计为恶手。阈值可调。 |
| 胜率、目差曲线 | 以黑方为视角，显示各手落子前的分析。 |

比例以有效评估手数为分母，终局停着单列。布局、中盘、官子默认按手数三等分，也可自选范围。暂停时保留当前窗口内已算完的结果。
