# 梓懿围棋 v1.7.0

2026-11-05：新增截图与实体棋盘照片摆棋。

- **截图 / 照片摆棋**（Ctrl+I）：选择图片、粘贴剪贴板图片，或在屏幕上框选截图，识别软件棋盘、视频截图与实体棋盘照片。
- **网格与透视校准**：自动定位后可拖动四角、设置可见行列和旋转图片，校正斜拍棋盘。角点对应可见网格的四角交叉点。
- **手动修正**：原图与还原棋盘并排对照，黑子 / 白子 / 擦除工具支持连续摆子及撤销；橙圈帮助核对疑点。
- **局部图定位**：选择实际全盘为 19 / 13 / 9 路，按真实角边或起始列行放回完整棋盘。截图裁切边不作为真实盘边，盘外缺失信息在题图中注明。
- **确认后研究**：选择下一手黑或白，导入为新的初始摆子局面，可接着研究并保存 SGF；取消保留原棋局。导入棋子不虚构历史手数，从导入后新落子开始编号。
- 图像识别在本机 CPU 离线完成，继续使用原来的 KataGo 引擎与模型。保留局部研究、全局对比、棋子手数、双向让子、CUDA / OpenCL / CPU 及计算深度选择。

## 使用提示

请在确认导入前核对棋子与格线。实体棋盘尽量拍清全部交叉点；模糊、强反光、遮挡和大角度拍摄可能需要校准并手动修正。

截图通常无法恢复落子顺序、先前提子数量和劫历史。局部图的全盘胜率与目差仅描述导入后搭建的局面；征子和劫争可能需要补充盘外信息或扩大研究范围。

## GPU 升级与首次安装

本版主程序继续使用 v1.4.0 的 CUDA / OpenCL 引擎、运行库与两个 GPU 模型。

- **已有 v1.4.0 完整 GPU 包，或已升级到 v1.5.0 / v1.6.0**：先关闭程序，将 v1.7.0 升级包内文件解压到原来的 `梓懿围棋.exe` 所在目录，覆盖同名文件，再运行更新后的程序。保留相邻的 `cuda` 与 `gpu` 文件夹，无需重下引擎或模型。
- **首次使用 GPU**：先下载并解压 [v1.4.0 CUDA / OpenCL 基础包](https://github.com/vict1238/ziyi-weiqi/releases/download/v1.4.0/ziyi-weiqi-Windows-CUDA-v1.4.0.zip)，再将 v1.7.0 升级包内文件解压到同一程序目录并覆盖，最后运行 `梓懿围棋.exe`。
- **只使用 CPU**：下载 v1.7.0 单文件程序即可使用内置 CPU 引擎与轻量模型。

CUDA 运行库由基础包提供，无需安装完整 CUDA Toolkit，仍需兼容的 NVIDIA 显卡和驱动。应用源码为 MIT；NVIDIA 运行库与 GPU 模型遵循各自的原始许可。

本版的图像识别、透视、手动编辑、SGF 导入及真实引擎验证结果见 `验证记录.txt` 与 `qa/image-import-test.txt`。README 性能表沿用 v1.4.0 的 36 次正式对比；历史版本及其附件继续保留。
