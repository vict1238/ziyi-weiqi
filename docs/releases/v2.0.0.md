# 梓懿围棋 v2.0.0

- 加入 Tailscale 和局域网好友房。切磋房支持悔棋确认、认输和断线续弈，开局后锁定本机 AI。
- 研讨房允许双方摆棋、导入棋谱、试下和共享 KataGo 推荐。
- SGF 整盘分析显示一选率、恶手率、目损和问题手。可以暂停续算，并加深关键手。

已有 GPU 版可下载[升级包](https://github.com/vict1238/ziyi-weiqi/releases/download/v2.0.0/ziyi-weiqi-Windows-Update-v2.0.0.zip)，退出程序后解压覆盖，保留 `cuda` 和 `gpu`。首次用 GPU 时先解压 [v1.4.0 基础包](https://github.com/vict1238/ziyi-weiqi/releases/download/v1.4.0/ziyi-weiqi-Windows-CUDA-v1.4.0.zip)。也可直接运行 [CPU 单文件版](https://github.com/vict1238/ziyi-weiqi/releases/download/v2.0.0/ziyi-weiqi-v2.0.0.exe)。
