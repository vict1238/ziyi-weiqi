# 梓懿围棋 v2.0.0

2026-11-06 发布。好友房支持切磋和共同研讨，复盘新增 SGF 整盘分析。

- **Tailscale 和局域网好友房**。房主选择网络并复制邀请，好友粘贴加入。房主同步棋局与规则，短时掉线可凭原座位恢复完整棋局。
- **切磋房**。按规则轮流落子，可停着、双方确认悔棋、认输、确认终局结果并保存 SGF。切磋期间锁定本程序的 AI 和摆棋。对局结束后可复制到研讨房。
- **研讨房**。双方都可摆黑白子、擦除、撤销、选下一手、浏览棋谱和试下。双方确认后可清盘或替换棋谱。两边各用本机 KataGo 计算，可分享全盘或局部结果。共享结果标明模型、搜索次数和对应局面。
- **SGF 整盘分析**。提供测评、吻合度、胜率与目差、问题手和发挥分布。对搜索不足的实战着点补算，按落子方视角比较。默认好手上限 1.5 目，恶手起点 6 目。可调整阈值、筛选手数与棋方、暂停续算或复算单手。
