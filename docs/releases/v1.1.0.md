# 梓懿围棋 v1.1.0

梓懿围棋是可离线运行的 Windows 围棋对弈与复盘工具。“关于”展示致敬语：致敬六大至尊围棋王“梓”和“懿”。

- 计算深度可选快速、标准、深入，也可自定义每步搜索次数。
- 有限搜索支持超过 32 位整数的目标，已验证 30 亿次预算的正确传递。KataGo 原生单次范围为 1 至 1125899906842624（2^50）；超出范围会提示选择持续思考，输入数值不会被截断。
- 持续思考模式使用原生最大搜索预算，分析不设置固定时长。搜索次数、胜率与当前最佳点实时更新，由用户手动结束。
- 点击“结束思考并落子”采用当时最佳着法；在推荐着点或领地分析中结束思考，则保留当前分析结果。

持续思考已实测运行超过 95 秒，手动停止后返回可用着法与领地结果。验证还包括 156 项规则与 SGF 断言、38 项自定义搜索解析断言，以及真实引擎、桌面设置、停止计算和新局取消检查。

支持 Windows 10 / 11 x64、.NET Framework 4.8，内置 KataGo CPU 引擎与 10 层模型。支持 9、13、19 路棋盘、中国及日本规则、AI 自弈，以及 SGF 主变化、初始摆子和先行方的读取与保存。

下载文件使用英文名；便携包解压后的主程序为 `梓懿围棋.exe`，程序界面使用中文。

解压源码后，在 PowerShell 中运行 `./build.ps1`；`./build.ps1 -Checks` 可执行规则、自定义搜索和真实引擎检查。

下载后可运行以下命令，将结果与本版本的 `SHA256SUMS.txt` 中同名文件一项比较：

```powershell
Get-FileHash -LiteralPath '.\ziyi-weiqi-v1.1.0.exe' -Algorithm SHA256
```

便携包和源码包也可用同一命令替换文件名校验。KataGo、模型与依赖的许可随下载文件提供。
