# 梓懿围棋 v1.3.0

本版加入带日期的模型选择，完整 GPU 便携包默认使用最强 tf3 模型，并提高搜索次数预设。

| 模型 | 日期 | 说明 |
| --- | --- | --- |
| `kata1-tf3-b11c768-s11003M-d5973M-7gres` | 2026-09-25 | GPU 默认；官方公开榜截至 2026-10-20 标记“评分可信的最强” |
| `kata1-b18c384nbt-s9996604416-d4316597426` | 2024-05-26 | 保留的原 GPU 模型 |
| `g170e-b10c128-s1141046784-d204142634` | 2020 年旧版；2020-11-28 官方收录 | 保留的内置 CPU 轻量模型 |

日期依据官方公开信息。GPU 模型日期为官方上传日期；g170 标注官方目录收录日期，原始训练完成日未记录。[官方模型榜](https://katagotraining.org/networks/)

- 从右侧“设置…”或“帮助 → 引擎 / 模型设置”选择模型，列表直接显示日期。确认后保留棋局并取消旧分析，取消则保留原设置。
- 完整 GPU 包首次运行默认最强模型；旧版默认内置配置升级时迁移到最强模型，新版明确选择和自定义路径会保留。CPU 单文件继续使用内置 CPU 资源。
- 预设为 **256 / 1024 / 2048 / 4096 / 8192 / 16384 次搜索**；启动时 GPU 默认 **2048 次**，CPU 默认 **256 次**，会话内切换模型沿用当前预算。自定义和持续思考继续可用。
- GPU 模型以原始名称保存在 `gpu/models`，`gpu/runtime.json` 记录来源、日期及校验值。使用固定模型标识与相对路径，移动完整便携包后仍可选择自带模型。
- GPU 继续使用 KataGo 1.18.1 OpenCL，需要显卡驱动支持，无需安装 CUDA。首次加载新模型或棋盘大小时可能调优数分钟，可以取消；此过程不限制后续单步分析时长。

搜索次数表示访问量（visits），不是推演手数或段位。最强模型通常需要更多计算时间，可按实际等待时间选择预算或手动结束分析。

RTX 4060 Laptop GPU、8 GB、OpenCL 实测：最强模型 1024 次约 5.14–6.42 秒，2048 次约 9.72–11.80 秒，4096 次约 21.95–22.38 秒。首次显卡调优约 4 分钟，缓存后加载约 3.2 秒。数值为两个 19 路测试局面的记录，均在完成调优后测量，逐次清空神经网络缓存。
