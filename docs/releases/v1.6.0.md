# 梓懿围棋 v1.6.0

2026-10-27：新增局部研究与棋子手数。

- **框选局部**：点击后在棋盘上拖出范围，黑白双方搜索与实际棋子落点限定在框内，保留整盘棋子、规则、贴目和劫历史。Esc 取消本次框选，保留原研究区域。
- **全局对比**：取得局部推荐后，可对照局部 A 与全局 A。仅执行一次全盘分析，不自动落子，也不清除研究框；下一次 AI 落子仍使用局部范围。“退出局部”恢复全盘对弈。
- 研究框在新对局、导入 SGF 时清除，在复盘导航时保留。区内没有当前方的合法落点时提示扩大范围或退出局部，不自动脱先或停着。
- 推荐着点显示 A–E 候选及 A 的最多 10 步变化；较短变化按引擎实际返回显示。局部推荐是神经网络与有限搜索在限定条件下的建议，不保证数学意义的最优解；征子、劫争和向外逃出可能需要扩大范围。
- **显示手数**：当前存活棋子标出原始第 N 手。停着计数但没有棋子编号，开局预摆不编号；提子后编号消失，同点再落显示新号，悔棋、导航与新分支按当前历史更新。
- 保留双向 0–9 子让子、CUDA / OpenCL / CPU、带日期的模型、六档搜索预算、自定义及持续思考。当前仍为本地对弈与复盘，联机对弈尚未实现。

## GPU 升级与首次安装

本版主程序继续使用 v1.4.0 的 CUDA / OpenCL 引擎、运行库与两个 GPU 模型。

- **已有 v1.4.0 完整 GPU 包，或已升级到 v1.5.0**：先关闭程序，将 v1.6.0 升级包内文件解压到原来的 `梓懿围棋.exe` 所在目录，覆盖同名文件，再运行更新后的程序。保留相邻的 `cuda` 与 `gpu` 文件夹，无需重下引擎或模型。
- **首次使用 GPU**：先下载并解压 [v1.4.0 CUDA / OpenCL 基础包](https://github.com/vict1238/ziyi-weiqi/releases/download/v1.4.0/ziyi-weiqi-Windows-CUDA-v1.4.0.zip)，再将 v1.6.0 升级包内文件解压到同一程序目录并覆盖，最后运行 `梓懿围棋.exe`。
- **只使用 CPU**：下载 v1.6.0 单文件程序即可使用内置 CPU 引擎与轻量模型。

CUDA 运行库由基础包提供，无需安装完整 CUDA Toolkit，仍需兼容的 NVIDIA 显卡和驱动。应用源码为 MIT；NVIDIA 运行库与 GPU 模型遵循各自的原始许可。

局部研究、棋子手数、相关界面与真实 CPU / CUDA 引擎的具体检查结果见 `验证记录.txt`。README 性能表沿用 v1.4.0 的 36 次正式对比；历史版本及其附件继续保留。

验证：2294项自动断言、206项新增局部研究/手数界面断言通过；真实CPU与CUDA局部/全局切换、候选及PV范围、完整领地和合法落子检查通过。
