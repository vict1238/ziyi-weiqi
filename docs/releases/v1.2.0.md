# 梓懿围棋 v1.2.0

本版提供 GPU 完整便携包、引擎与模型选择、统一棋盘显示坐标，以及野狐棋谱贴目兼容。

- GPU 套件使用官方 KataGo 1.18.1 OpenCL 与 `kata1-b18c384nbt-s9996604416-d4316597426`，即 2024-05-26 的 18 层、384 通道嵌套瓶颈模型。CPU 单文件保留 KataGo 1.14.1 与 g170 b10（2020）轻量模型。
- 在右侧“设置…”或帮助菜单中选择 CPU、GPU、自定义 KataGo 程序及模型文件。确认后保留棋局并取消旧分析，设置会保存到本机。
- 19 路棋盘列为 A–S，包含 I；行从顶部 1 到底部 19。落子、复盘、推荐和搜索进度使用一致的显示坐标。
- 识别野狐 SGF 的贴目编码并在状态栏说明转换；贴目范围统一为 −150 至 150，支持整数与半目。
- CPU / GPU 启动与模型加载可取消；引擎切换后旧状态、旧进度与旧结果不会修改当前棋局。
- 实际落子播放原创落盘音效；“规则 / 设置”提供 0–100% 音量及试听，确认后立即生效并保存，0% 为静音。

快速、标准、深入继续使用 16 / 64 / 256 次搜索。256 表示访问次数（visits），不是推演 256 手或人类段位。模型质量和搜索预算共同决定棋力；GPU 的作用是提高计算吞吐量，相同模型和访问次数下不会自动升级模型能力。GPU 可先尝试自定义 4096 次，并按实际耗时调整。

适用于 Windows 10 / 11 x64、.NET Framework 4.8。GPU 包需要显卡驱动的 OpenCL 支持，无需安装 CUDA；首次调优可能需要几分钟。准备完成后可以离线运行。

GPU 包解压后运行 `梓懿围棋.exe`，并保持 `gpu` 文件夹与主程序相邻。没有已保存设置时会默认选择 GPU；已有设置可在界面中修改。

解压源码后，在 PowerShell 中运行：

```powershell
.\build.ps1
.\prepare-gpu.ps1
```

GPU 准备脚本下载固定版本并核验 SHA-256；已有下载可通过 `-SourceCache` 复用。模型原始名称与校验值记录在 `gpu/runtime.json`，原始许可位于 `gpu/licenses`。

下载校验示例：

```powershell
Get-FileHash -LiteralPath '.\ziyi-weiqi-Windows-GPU-v1.2.0.zip' -Algorithm SHA256
```

将结果与 `SHA256SUMS.txt` 中同名文件比较。CPU g170 模型采用 CC0；GPU kata1 b18 模型采用 KataGo Neural Network License，完整声明随下载包保留。
