## GPU 升级与首次安装

本版主程序沿用 v1.4.0 的 CUDA / OpenCL 引擎、运行库与两个 GPU 模型，提供小体积升级包。

- **已有 v1.4.0 完整 GPU 包**：先关闭程序，将 v1.5.0 升级包内文件解压到原来的 `梓懿围棋.exe` 所在目录，覆盖同名文件，再运行更新后的程序。保留相邻的 `cuda` 与 `gpu` 文件夹，无需重下引擎和模型。
- **首次使用 GPU**：先下载并解压 [v1.4.0 CUDA / OpenCL 基础包](https://github.com/vict1238/ziyi-weiqi/releases/download/v1.4.0/ziyi-weiqi-Windows-CUDA-v1.4.0.zip)，再将 v1.5.0 升级包内文件解压到同一程序目录并覆盖，最后运行 `梓懿围棋.exe`。
- **只使用 CPU**：下载 v1.5.0 单文件程序即可使用内置 CPU 引擎与轻量模型。

CUDA 运行库由基础包提供，无需安装完整 CUDA Toolkit，仍需兼容的 NVIDIA 显卡和驱动。应用源码为 MIT；NVIDIA 运行库与 GPU 模型遵循各自的原始许可。

验证：2008 项规则、SGF、配置、坐标和声音断言通过；新增 134 项让子界面断言通过；真实 CPU / CUDA 分析、完整 ownership 和双方 AI 首手检查通过。详细记录见 `验证记录.txt`。

本版未重新测量 CUDA / OpenCL 加速倍数，README 的性能表沿用 v1.4.0 的 36 次正式对比。历史版本及其附件继续保留。
